====================================
Rouse Model Experimentation Protocol
====================================

Reference: Kuriata, Gront & Sikorski (2016) CMST 22(4), 179–185; Rouse (1953) J. Chem. Phys. 21(7), 1272–1280.

1  Objective
============

Conduct a complete Rouse-model Monte Carlo simulation campaign over multiple chain lengths and volume fractions. Collect static and dynamic observables and generate diagnostic plots that demonstrate the simulation reproduces the scaling laws predicted by Rouse theory and validated by Kuriata et al. (2016).

2  Simulation Parameters
========================


2.1  Physical Constants
-----------------------


+-------------------------+--------+------------------------------------+
| Parameter               | Symbol | Value                              |
+=========================+========+====================================+
| Bead diameter           | σ      | 3.8 Å                              |
+-------------------------+--------+------------------------------------+
| Equilibrium bond length | l₀     | 5.7 Å  (l₀/σ = 1.5)                |
+-------------------------+--------+------------------------------------+
| Temperature             | T      | 300 K (athermal; energy in kJ/mol) |
+-------------------------+--------+------------------------------------+
| Hard-core repulsion     | E_rep  | 10⁶ kJ/mol  (r < σ)                |
+-------------------------+--------+------------------------------------+


2.2  State-Point Grid
---------------------

The campaign sweeps a grid of chain lengths and volume fractions:

+--------------------+-------------------------------------------------+
| Parameter          | Values                                          |
+====================+=================================================+
| Chain lengths N    | 25, 50, 100, 250, 500                           |
+--------------------+-------------------------------------------------+
| Volume fractions φ | 0.001, 0.01, 0.05, 0.10, 0.20, 0.30  (6 levels) |
+--------------------+-------------------------------------------------+

This produces 5 × 6 = 30 state points. The box length is computed as L = (n_chains × N × σ³ / φ)^(1/3). Chain count is scaled by density via compute_n_chains().

2.3  Monte Carlo Move Set
-------------------------


+--------------------------+-----------+--------------------------------------------------+
| Move                     | Max Angle | Selection                                        |
+==========================+===========+==================================================+
| Hinge (interior segment) | π/2       | Segment chosen uniformly; rotation via Rodrigues |
+--------------------------+-----------+--------------------------------------------------+
| N-terminal tail          | π/2       | Rotates beads [0, seg_end)                       |
+--------------------------+-----------+--------------------------------------------------+
| C-terminal tail          | π/2       | Rotates beads [seg_start, N)                     |
+--------------------------+-----------+--------------------------------------------------+
| Pivot                    | π         | N- or C-half with 50/50 probability              |
+--------------------------+-----------+--------------------------------------------------+

Segment size: 20 beads per segment (RESIDUES_PER_SEGMENT). All moves use the segmented multistep MC algorithm with matrix-based energy computation and rank-1 correction (E11 − E01 − E10 + E00).

2.4  Energy Function
--------------------

Three-zone excluded-volume (CA contact energy):
  * r < σ  →  E = 10⁶ kJ/mol  (hard-core repulsion)
  * σ ≤ r < 2σ  →  E = 0 kJ/mol  (contact shell, athermal)
  * r ≥ 2σ  →  E = 0 kJ/mol  (no interaction)

3  Experimental Procedure
=========================


3.1  Initialization
-------------------

  * For each state point (N, φ), compute box size L and chain count.
  * Initialize chains using serpentine grid placement (or random walk). Verify all bond lengths equal l₀ = 5.7 Å.
  * Set reproducible RNG seeds via set_all_seeds (numpy, torch, Python random).
  * Verify no chain overlaps at initialization and that φ is physically reasonable.

3.2  Equilibration Phase
------------------------

Run MC sweeps until static observables plateau. Track ⟨R²⟩ and ⟨Rg²⟩ as running time-averages (static_vs_sweep) to confirm convergence. No production data is collected during this phase. Longer chains require more equilibration sweeps.

3.3  Production Phase
---------------------

After equilibration is confirmed, begin collecting observables:
  * Record static snapshots (R², Rg² per chain) every sample_interval = 5 sweeps.
  * Accumulate dynamic time-lagged data via DynamicAccumulator (g₁, g_CM, g_R).
  * Continue production sweeps long enough that the longest relaxation time τ_R is well exceeded for each chain length (critical for N = 250, 500).

3.4  Post-Processing & Analysis
-------------------------------

After all state points complete:
  * Write TSV data files (5 per state point: static, g₁, g_CM, g_R, sweep tracker).
  * Compute derived quantities: power-law exponents, D from late-time g_CM slope, τ_R from g_R 1/e crossing.
  * Generate all diagnostic and validation plots (see Section 5).
  * Write validation summary JSON with pass/fail against acceptance criteria.

4  Validation Properties
========================


4.1  Static Properties (Equilibrium Chain Dimensions)
-----------------------------------------------------

These properties characterize the time-averaged spatial extent of polymer chains at equilibrium. They depend only on chain length N, not on time.
P1 [STATIC]  End-to-end distance squared ⟨R²⟩ scales as N^(2ν) with 2ν ≈ 1.18 (self-avoiding walk exponent).
  * Acceptance: Power-law fit on log-log plot yields 2ν within ±0.15 of 1.18; R² > 0.99.
P2 [STATIC]  Radius of gyration squared ⟨Rg²⟩ scales as N^(2ν) with 2ν ≈ 1.18.
  * Acceptance: Same criteria as P1.
P3 [STATIC]  Universal amplitude ratio ⟨R²⟩/⟨Rg²⟩ converges to ≈ 6.25 for large N (3D SAW asymptote).
  * Acceptance: Ratio within [6.0, 6.5] for N ≥ 50.

4.2  Dynamic Properties (Time-Dependent Observables)
----------------------------------------------------

These properties describe how polymer chains move and relax over time. They require production-phase time series of sufficient length.
P4 [DYNAMIC]  Center-of-mass MSD g_CM(t) is diffusive: g_CM ∝ t with exponent ≈ 1.0 at long times.
  * Acceptance: Late-time log-log slope within [0.85, 1.15] for well-equilibrated chain lengths.
P5 [DYNAMIC]  Middle-segment MSD g₁(t) shows sub-diffusive scaling g₁ ∝ t^0.5 at short times (Rouse regime), crossing over to diffusive (t^1.0) at long times.
  * Acceptance: Short-time log-log slope within [0.4, 0.6] for N ≥ 100.
P6 [DYNAMIC]  End-to-end vector autocorrelation g_R(t) decays toward zero. The longest relaxation time τ_R (1/e crossing) scales as τ_R ∝ N^(2.18±0.4).
  * Acceptance: Power-law fit exponent in [1.8, 2.6]; R² > 0.97.
P7 [DYNAMIC]  Diffusion coefficient D scales as D ∝ N^(−1). In athermal SAW chains excluded-volume effects may steepen the slope.
  * Acceptance: Power-law exponent negative; R² > 0.95.

4.3  Rouse (1953) Theoretical Properties (Nice to Have)
-------------------------------------------------------

The following properties derive from the original Rouse (1953) theory. They are desirable but not mandatory for validation. Some require capabilities beyond the current MC engine (marked below).
P8 [STATIC]  Gaussian submolecule probability follows ψ(x,y,z) = (β/π)^(3/2) exp[−β(x²+y²+z²)] with β = 3/(2σ²).
P9 [STATIC]  Rouse matrix eigenvalues λ_p = 4 sin²[pπ/(2(N+1))] for p = 1, …, N.
P10 [DYNAMIC]  Normal-mode relaxation times τ_p = σ²/[24BkT sin²(pπ/(2(N+1)))] for each mode p.
P11 [DYNAMIC]  Long-wavelength relaxation times τ_p ≈ σ²N²/(6π²p²BkT) for p ≪ N.
P12 [DYNAMIC]  [REQUIRES MD] Steady-flow viscosity η₀ = η_s + nσ²N(N+2)/(36B).
P13 [DYNAMIC]  [REQUIRES MD] Complex viscosity components η₁ and η₂ under oscillatory shear.
P14 [DYNAMIC]  [REQUIRES MD] Complex shear modulus G₁ (storage) and G₂ (loss).
P15 [STATIC]  [REQUIRES HARMONIC BOND] Harmonic bond potential U_ij = k(l_ij − l₀)² between nearest-neighbor beads.

7  How to Run
=============

Full 30-state-point campaign:
    python -m rouse_model_python.run_campaign --device gpu --is_parallel true

Reference campaign (φ = 0.035 only, matches C# deliverable):
    python -m rouse_model_python.run_reference_campaign --device gpu --is_parallel true

Supported --device options: cpu, gpu, mixed. The execution policy auto-resolves step size, batch mode, and multi-GPU partitioning.
