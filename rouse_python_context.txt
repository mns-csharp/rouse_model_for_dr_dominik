OBJECTIVE
=========

Validate that the SURPASS-alpha coarse-grained (CG) polymer representation
abides by Rouse static and dynamic properties as published in:

  [REF-1] Kuriata, A., Gront, D. & Sikorski, A., CMST 22(4), 179-185 (2016)
  [REF-2] Rouse, P.E. Jr., J. Chem. Phys. 21(7), 1272-1280 (1953)

Specifically:
  (a) Prove compliance with all static and dynamic Rouse properties in [REF-1].
  (b) Determine which Rouse properties in [REF-2] ARE met by SURPASS-alpha.
  (c) Determine which Rouse properties in [REF-2] are NOT met by SURPASS-alpha.
  (d) Map how Rouse property compliance changes across a progression of
      increasing chain densities (phi), from dilute to dense regimes.
  (e) Produce publication-quality plots and structured data for all findings.

Key physical clarifications confirmed by Dr. Dominik Gront (30 Mar 2026):
  -- The excluded volume energy E is INFINITE. Any move violating excluded
     volume is ALWAYS rejected regardless of simulation temperature. This
     makes the system effectively athermal: temperature is irrelevant to the
     accept/reject decision because exp(-inf/kBT) = 0 for all finite T.
  -- Concentration (phi) is NOT fixed at a single value. A progression of
     increasing densities must be tested to map where and how Rouse behavior
     is fulfilled, weakened, or broken.

CONSTRAINTS
===========

EXCLUDED VOLUME (FIXED -- NON-NEGOTIABLE):
  - The excluded volume energy barrier E is INFINITE.
  - Implementation: any MC move that causes bead overlap (rij <= dk) is
    ALWAYS rejected with probability 1.
  - RepulsiveEnergy = 1e6 in SURPASS-alpha is the practical approximation
    of infinity. Verify that this is large enough that no overlapping
    configuration is ever accepted. Document this verification.
  - ContactEnergy = 0 (no attractive interaction of any kind).
  - Temperature does NOT appear anywhere as a simulation parameter.
    The Boltzmann accept/reject criterion reduces to: accept if no overlap,
    reject if overlap. Temperature cancels out completely.

SURPASS-ALPHA FIXED PARAMETERS:
  - sigma        = 3.8 A  (Calpha bead diameter, d0)
  - l0           = 5.7 A  (bond spacing, chosen by Mohammad Nazmul Saqib)
  - l0/d0        = 1.5    (must be verified against Kuriata Fig. 3 to confirm
                           it places SURPASS-alpha in the correct SAW scaling
                           regime yielding 2nu ~ 1.20)
  - MC moves:    Segmented hinge + N-tail + C-tail (local) + pivot (global)
  - Init:        Random walk (self-avoiding off-lattice) for ALL chain lengths
  - Chain lengths N: 25, 50, 100, 250, 500

DENSITY PROGRESSION (CORE REQUIREMENT -- confirmed by Dr. Dominik Gront):
  Simulations MUST be run across the following phi levels for ALL chain lengths.
  Worker agents must determine chain counts, box sizes, and sweep schedules.
  Equilibration must occur in <= 10000 sweeps for ALL N at ALL phi levels.

  phi levels: 0.001 (effectively dilute), 0.01, 0.05, 0.10, 0.20, 0.30

  This gives a 5 x 6 simulation matrix (N x phi) = 30 state points.

  For each state point, workers must fill this table:
  +-----+-------+--------+-----------+-------------+---------+
  | N   | phi   | Chains | Eq Sweeps | Prod Sweeps | Box (A) |
  +-----+-------+--------+-----------+-------------+---------+
  |  25 | 0.001 |   ?    |     ?     |      ?      |    ?    |
  |  25 | 0.01  |   ?    |     ?     |      ?      |    ?    |
  |  25 | 0.05  |   ?    |     ?     |      ?      |    ?    |
  |  25 | 0.10  |   ?    |     ?     |      ?      |    ?    |
  |  25 | 0.20  |   ?    |     ?     |      ?      |    ?    |
  |  25 | 0.30  |   ?    |     ?     |      ?      |    ?    |
  |  50 | 0.001 |   ?    |     ?     |      ?      |    ?    |
  | ... | ...   |  ...   |    ...    |     ...     |   ...   |
  | 500 | 0.30  |   ?    |     ?     |      ?      |    ?    |
  +-----+-------+--------+-----------+-------------+---------+

  Box size derivation: L_box = sigma * (N_chains * N / phi)^(1/3)
  Document derivation for every state point. Verify L_box is consistent
  with phi for each entry.

  Parallelization: independent state points are trivially parallel.
  The framework must support both CPU and GPU parallelization.
  Assign state points across workers to maximize parallel throughput.

            Document this verification in iteration_log.txt.
  Step 0.7: Create the full output directory tree under the output root.

PHASE 1 -- STATIC PROPERTIES (01_static_properties/):
  For each (N, phi) state point in the 30-point matrix:
    1.1  Run MC simulation to equilibration. Verify R2 and Rg2 converge.
    1.2  Collect production trajectory.
    1.3  Compute ensemble-averaged <R2>.
    1.4  Compute ensemble-averaged <Rg2>.
    1.5  Compute ratio <R2>/<Rg2>.
    1.6  Fit power law vs N at this phi: <R2> ~ N^(2nu). Record 2nu and R^2.
    1.7  Fit power law vs N at this phi: <Rg2> ~ N^(2nu). Record 2nu and R^2.
    1.8  Save data to 05_data/phi_{phi}/N{N}/fig1_static.tsv.
    1.9  Save sweep-resolved data to 05_data/phi_{phi}/N{N}/static_vs_sweep.tsv.

  Cross-phi analysis:
    1.10 Plot 2nu (from R2) vs phi -- how does scaling exponent change with
         density? Mark Kuriata target (2nu = 1.20) as reference line.
    1.11 Plot <R2>/<Rg2> ratio vs phi for all N overlaid.
    1.12 Generate all figures in 01_static_properties/ (see DELIVERABLES).

PHASE 2 -- DYNAMIC PROPERTIES (02_dynamic_properties/):
  For each (N, phi) state point:
    2.1  Compute g1(t): MSD of middle segment (index ~ N/2).
    2.2  Compute g_CM(t): MSD of chain center of mass.
    2.3  Compute diffusion coefficient D from long-time slope of g_CM(t).
    2.4  Compute tau_R from end-to-end autocorrelation gR(t) using
         equations (8) and (9) from [REF-1].
    2.5  Save all dynamic data to 05_data/phi_{phi}/N{N}/ (see DELIVERABLES).

  Cross-phi analysis:
    2.6  Plot D vs N at each phi level overlaid. Show how D ~ N^-1 breaks
         down as phi increases.
    2.7  Plot tau_R vs N at each phi level overlaid. Show exponent drift
         with density.
    2.8  Plot g1(t) short-time exponent vs phi. Mark theoretical 0.5 and
         Kuriata observed 0.60 as reference lines.
    2.9  Generate all figures in 02_dynamic_properties/ (see DELIVERABLES).

PHASE 3 -- EQUILIBRATION EVIDENCE (04_equilibration_evidence/):
  3.1  For each phi level: plot R2 vs MC sweep for all N overlaid.

  3.2  For each phi level: plot Rg2 vs MC sweep for all N overlaid.

AGENT ARCHITECTURE
==================

FIVE WORKER AGENTS (W1 -- W5):
  The 30 state points are distributed across workers as follows:
    W1: N=25,  all 6 phi levels
    W2: N=50,  all 6 phi levels
    W3: N=100, all 6 phi levels
    W4: N=250, all 6 phi levels
    W5: N=500, all 6 phi levels + all cross-phi figures + compliance map

  Each worker MUST at the start of each iteration:
    (a) Read requirements_list.md.
    (b) Declare explicitly which REQ IDs it will complete this iteration.
    (c) Promise no shortcuts, stubs, or skipped sub-steps.
  Each worker logs start, commits, progress, and completion to iteration_log.txt.

SUPERVISOR AGENT:
  - Monitors all five workers throughout each iteration.
  - At iteration end, reviews every commit against requirements_list.md.
  - Flags any commit that is incomplete, stubbed, missing, incorrect,
    or contains temperature as a simulation parameter.
  - Verifies that all 30 state points are covered -- not just a subset.
  - Writes Supervisor Report to iteration_log.txt with verdict per commit.
  - Cannot approve iteration as complete if any commit is flagged.

MANAGER AGENT:
  - Monitors the Supervisor.
  - Verifies Supervisor checked EVERY commit with quantitative evidence.
  - Verifies Supervisor confirmed all 6 phi levels present for all 5 N.
  - Rejects Supervisor Report if superficial. Requires redo.
  - Writes Manager Verdict to iteration_log.txt.

TIMEKEEPER AGENT:
  - Acts after Manager Verdict.
  - Reads requirements_list.md, counts PENDING items.
  - Verifies all declared output files exist on disk.
  - Verifies all 30 state point data directories exist and are non-empty.
  - Opens new iteration if anything is missing.
  - Writes DONE only when everything is complete and verified on disk.
  - Never accepts a worker's word. Verifies files on disk only.

SENTINEL AGENT:
  - Runs independently once per iteration.
  - Checks for ALL of the following violations:
      (a) Temporary files other than requirements_list.md and iteration_log.txt
      (b) Stubs, TODOs, or placeholders in any output file
      (c) Plots missing axis labels, units, or legend
      (d) Scaling fits missing R^2 or exponent value
      (e) Equilibration exceeding 10000 sweeps without documentation
      (f) Temperature appearing as a simulation parameter in any script
      (g) Fewer than 6 phi levels simulated for any N value
      (h) Missing state points in the 30-point matrix
      (i) Box size inconsistent with the stated phi for any state point
      (j) RepulsiveEnergy < 1e6 in any simulation config
      (k) Any claim that Kuriata 2016 specified a phi value -- they did not
      (l) Compliance heatmap missing phi* analysis
  - Lists all violations under SENTINEL ALERT in iteration_log.txt.
  - Blocks iteration closure until all violations are resolved.
  - Sentinel findings cannot be overridden by any other agent.
