Initialization & Setup
(13) Chain initialization produces valid configurations (serpentine grid and random walk both yield correct bond lengths of l0 = 5.7 A)
(14) Box size is correctly computed from volume fraction phi = 0.035 for each chain length
(15) Seed setting (set_all_seeds) ensures reproducibility across numpy, torch, and Python random
PBC / Geometry
(16) Chain unwrapping (unwrap_chains via bond vectors + cumsum) gives correct end-to-end distances across periodic boundaries
(17) Anchor-relative unwrapping (unwrap_chain_from_anchor) is consistent with full sequential unwrapping
(18) Cell-list grid indices respect PBC (27-neighbor offsets with periodic wrapping)
Energy
(19) Three-zone excluded-volume kernel returns correct values in each regime (r < sigma -> 1e6, sigma <= r < 2*sigma -> contact, r >= 2*sigma -> 0)
(20) Cell-list neighbor gathering produces the same delta-E as brute-force all-pairs computation
(21) Rank-1 energy correction in multistep MC (E11 - E01 - E10 + E00) matches recomputed full delta-E
(22) FP32 GPU energy kernels agree with FP64 CPU results within acceptable tolerance
(23) Cell list is rebuilt between batches so accepted moves are reflected in neighbor lookups
MC Moves
(24) Hinge move rotates only the interior segment [seg_start, seg_end) while anchor beads remain fixed
(25) Rodrigues rotation matrix is orthogonal (R*R^T = I) and preserves bond lengths exactly
(26) Random SO(3) matrices (Marsaglia method) produce uniform rotational sampling
(27) Degenerate rotation axes (length < 1e-7) are handled gracefully with fallback to orthogonal axis
(28) Pivot move selects N-terminal vs C-terminal half with equal probability (50/50)
Metropolis & Acceptance
(29) Metropolis criterion handles overflow correctly (exp bounds clamped to [-745, 709])
(30) Acceptance rates are tracked separately per move type (hinge, N-tail, C-tail, pivot)
(31) delta-E = 0 moves are always accepted
Batch / GPU Path
(32) BatchProposal padding masks correctly exclude padded beads from energy computation
(33) Self-interaction masking in batched delta-E kernel prevents a bead from interacting with itself
(34) RandPool pre-generation eliminates per-call GPU-to-CPU sync overhead and refills correctly
